# Stars Makers

Démonstration responsive, entièrement côté interface, d’une communauté de
karaoké. Les artistes et les morceaux sont fictifs. La confirmation d’âge, les
crédits de démonstration et la participation sont conservés dans le stockage
local de ce navigateur.

Ouvrir directement `index.html` ou servir ce dossier en local :

```bash
python -m http.server 8000
```

Puis accéder à `http://localhost:8000`.

Les enregistrements, invitations à des duos, concours, cadeaux et choix
d’abonnement sont des simulations. Il n’y a ni capture depuis le microphone,
ni lecture musicale, ni gestion de comptes, ni vérification réelle de l’âge,
ni traitement de paiement, ni catalogue musical sous licence.
